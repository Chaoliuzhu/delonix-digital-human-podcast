# Delonix Digital Human Podcast

Generate a ~1 minute digital-human podcast video end-to-end. The pipeline was battle-tested
end-to-end (2026-10-27, Xi'an AI Native share page): script → TTS → portrait composite → s2v
segments → glass-subtitle assembly → web embed.

## Prerequisites

- Aliyun Bailian workspace API key with these models enabled: `wan2.2-s2v` (video), `wan2.7-image`
  (image gen/edit), `cosyvoice-v3-flash` or `qwen-audio-3.1-tts-next` (TTS).
  Configure via `bl auth login --config <profile> --api-key <key> --base-url <workspace-maas-url>`
  or call raw APIs with the key directly (see references/api-notes.md).
- ffmpeg (no drawtext/subtitles filters needed — overlays are PNG-based), Python 3 with Pillow.
- Fallback TTS: open-source Piper (works offline, but robotic — use only as last resort).

## Pipeline (7 steps)

### 1. Script

Write a ~300-350 character Chinese script (≈60-70s at natural TTS pace). Structure: identity
hook → 2-3 concrete numbers → mechanism/what-changed → honest-data bottom line → meta closer
("this face is generated by..."). Keep each sentence a standalone fact; sentences become subtitle
units and audio segment boundaries.

### 2. TTS per sentence

Synthesize **each sentence as a separate audio file** (not one long track) — this makes segment
packing and subtitle timing trivial.

- Preferred: `cosyvoice-v3-flash` via `bl speech synthesize --config <profile> --voice longtian_v3`
  (male, authoritative) — pick voice by presenter gender/persona. Run `--list-voices` first.
- Voice consistency across sessions: clone with `qwen-audio-3.1-tts-next` passing an existing clip
  as reference — see references/api-notes.md (bl CLI has a bug for this model; use raw curl).
- Robotic fallback: Piper (huayan etc.), acceptable for internal drafts only.

### 3. Pack audio segments (hard limit: 20s)

`wan2.2-s2v` rejects audio longer than 20s. Greedily pack consecutive sentences into segments
≤19s (sentence gap ≈0.35s via ffmpeg concat). Typical 65s script → 4-5 segments. Record each
segment's audio duration — subtitle timing is calibrated from it.

### 4. Portrait / base image

Two paths:
- AI persona: `bl image generate --model wan2.7-image --size 3:4` with a portrait prompt
  (direct gaze, closed mouth, simple background).
- Real person: `bl image edit --model wan2.7-image --image <selfie> --image <background-photo>`
  with a prompt that explicitly preserves face/glasses/clothing and composites into the background
  (slight background blur, direct gaze). Use a REAL venue photo as background for authenticity —
  hotel lobbies etc. work far better than generated ones.

Requirements: front-facing, mouth closed, eyes to camera, 3:4 ratio. Output 720x1048-ish.

### 5. Submit s2v tasks (parallel)

For each audio segment: upload portrait + audio to DashScope temp storage, then submit async
`wan2.2-s2v` tasks. Full working code: `scripts/s2v_pipeline.py` (upload → submit → poll →
download). Critical details in references/api-notes.md:
- Endpoint is `image2video/video-synthesis`, NOT `video-generation/...` (wrong path → misleading
  "url error").
- oss:// URLs need header `X-DashScope-OssResourceResolve: enable`.
- Poll via the STANDARD endpoint `dashscope.aliyuncs.com/api/v1/tasks/{id}` — the workspace MaaS
  endpoint may 403 on task queries once quota is exhausted, even for already-submitted tasks.
- Runtime ~4-7 min per segment, parallelizable. 720P ≈ ¥0.9/s of video.

### 6. Assemble with glass overlays

`scripts/assemble_final.py` does:
1. Title card via **PIL** (system ffmpeg usually lacks drawtext — never rely on it).
2. Video concat (title + segments, same WxH/fps required).
3. **Audio-track rebuild**: concat demuxer silently DROPS the audio track when mixing silent
   title + voiced segments. Rebuild separately: 2s silence + each segment's audio → single WAV.
4. Glassmorphism overlays generated by `scripts/make_overlays.py`: bottom gradient RGBA subtitle
   strips (per sentence, no black bars) + top semi-transparent carousel cards. Overlay chain:
   `[N:v]overlay=...:enable='between(t,a,b)'[vN]` chained, watch the trailing
   `[label]format=yuv420p[vout]` bracket syntax.
5. Subtitle timing: global time = title duration + cumulative segment mp4 durations; scale
   per-sentence audio durations by `segment_mp4_dur / segment_audio_dur` to absorb mux drift.
6. `loudnorm=I=-16:TP=-1.5:LRA=11` + `+faststart` → dual-stream H.264/AAC MP4.

### 7. Embed into a share page (optional)

Compress: `ffmpeg -i final.mp4 -vf scale=540:-2 -crf 27 -c:a aac -b:a 96k` (~2.4MB for 70s).
If the site protects non-HTML assets behind a share-code query param, relative-path `src` gets
403 — either hardcode `src="video.mp4?sharecode=XXX"` (the browser never auto-appends the query
when loading relative resources) or inline as base64 data URI. Redeploy the static directory
after adding the file.

## Quota & cost notes

- Free-tier workspaces exhaust `wan2.2-s2v` fast (~100s of 720P video). TTS and s2v quotas are
  separate; qwen-audio TTS may outlive cosyvoice. Check before re-running segments.
- Re-running one segment costs only that segment; keep per-segment assets (audio, task ids) so
  replacements are surgical.
- Task results (`video_url`) expire in 24h — download immediately.

## Files

- `scripts/make_overlays.py` — glass subtitles + carousel cards (PIL, RGBA)
- `scripts/assemble_final.py` — title card, concat, audio rebuild, overlay chain, loudnorm
- `references/api-notes.md` — exact endpoints, params, and every trap found in practice
